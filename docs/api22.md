\# API документация



\## Общая информация



Базовый URL: `https://api.example.com/v1`



Формат данных: JSON



Аутентификация: Bearer Token (JWT)



\## Эндпоинты



\### GET /students



Получение списка студентов



\*\*Параметры запроса:\*\*



| Параметр | Тип | Обязательный | Описание |

|----------|-----|--------------|----------|

| group | string | нет | Фильтр по группе |

| course | int | нет | Фильтр по курсу |

| limit | int | нет | Количество записей (по умолч. 20) |

| offset | int | нет | Смещение для пагинации |



\*\*Пример запроса:\*\*

```bash

curl -X GET "https://api.example.com/v1/students?group=ИВТ-201\&limit=10" \\

&#x20; -H "Authorization: Bearer ваш\_токен"



Пример ответа:

json

{

&#x20; "success": true,

&#x20; "data": \[

&#x20;   {

&#x20;     "id": 1,

&#x20;     "last\_name": "Иванов",

&#x20;     "first\_name": "Иван",

&#x20;     "group": "АПИб-22",

&#x20;     "course": 2

&#x20;   }

&#x20; ],

&#x20; "total": 25,

&#x20; "limit": 10,

&#x20; "offset": 0

}



POST /students

Создание нового студента

Тело запроса:

json

{

&#x20; "last\_name": "Петров",

&#x20; "first\_name": "Петр",

&#x20; "middle\_name": "Петрович",

&#x20; "birth\_date": "2005-03-15",

&#x20; "group": "ИВТ-202",

&#x20; "student\_id": "2024002"

}



Ответ:

json

{

&#x20; "success": true,

&#x20; "data": {

&#x20;   "id": 2,

&#x20;   "message": "Студент успешно создан"

&#x20; }

}
